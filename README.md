# Замоделька — Веб-САПР для проектирования инженерных систем и архитектуры

«Замоделька» (Zamodelka) — это высокоэффективная трехмерная веб-САПР система для проектирования вентиляции, отопления, электрики, сантехники и архитектурных планов. Система разработана на базе современного графического стека **That Open Engine** (наследник xeokit/Three.js) с высокой производительностью рендеринга и локальной обработкой BIM-данных.

---

## Ключевой реализованный функционал

### 1. Интеллектуальный Диспетчер проекта (Project Browser)
Удобное таб-меню в левой верхней части экрана, разделенное на логические вкладки:
*   **Параметры:** Интерактивное управление свойствами текущего черчения (сортамент, формы воздуховодов/труб/лотков, шаг углов).
*   **Уровни:** Полноценный высотный конфигуратор здания. Позволяет создавать новые отметки перекрытий, задавать им высоты в миллиметрах и удалять пользовательские уровни. **Клик по уровню мгновенно переключает активную рабочую высоту черчения** во всех инструментах.
*   **Системы:** Диспетчер инженерных сетей с динамическим выбором цвета (синий, красный, зеленый, коричневый, черный и т.д.). Изменение цвета системы мгновенно перекрашивает все соответствующие воздуховоды и фасонные изделия на сцене.
*   **Модели:** Модуль загрузки физических IFC-файлов и бинарных Fragment-моделей в реальном времени.

### 2. Умная привязка SmartSnap (в стиле Miro/Visio)
При черчении стен, воздуховодов, лотков, трубопроводов или размещении оборудования/колонн система анализирует сцену и **автоматически строит направляющие линии выравнивания (тонкие желтые маркеры)** по осям X и Z относительно ребер и геометрических центров других объектов в радиусе 300 мм. Это гарантирует идеально ровное черчение без ручного ввода координат.

### 3. Интерактивное переключение отметок (высот) при черчении [НОВОЕ]
Во время активной трассировки воздуховодов, трубопроводов или кабельных лотков:
*   **Ввод длины:** По умолчанию нажатие цифр на клавиатуре задает точную длину текущего прямого сегмента в мм.
*   **Ввод отметки через Tab:** Нажатие клавиши **`Tab`** переключает CAD-подсказку у курсора в режим ввода высоты (`⌨️ Ввод отметки: XXX мм`). При вводе числа и нажатии `Enter` система:
    1.  Автоматически строит **вертикальный подъем или опуск** (вертикальный сегмент) от текущей точки до новой высоты.
    2.  Перемещает рабочую плоскость черчения на новую высоту.
    3.  Позволяет бесшовно продолжить черчение горизонтальной трассы на новой отметке.
*   Повторное нажатие `Tab` возвращает в режим ввода длины.

### 4. Продвинутое подключение воздухораспределителей [НОВОЕ]
Изменен механизм размещения диффузоров и решеток для устранения неудобств принудительного перетаскивания:
1.  **Свободное размещение:** Оконечные устройства свободно ставятся в помещении на активном уровне пола/потолка.
2.  **3D-Подключение по кнопке:** При выборе размещенного прибора в правой панели свойств появляется синяя кнопка **«Подключить к воздуховоду»**.
3.  **Автотрассировка ответвления:** Клик по кнопке активирует режим привязки. При наведении мыши на любой воздуховод отображается фантомное превью врезки, а клик по нему строит оптимальный соединительный воздуховод (сечение наследуется от родительского с пропорциональным переходом) и автоматически врезает тройник/отвод через генератор фасонных изделий `FittingGenerator`.

### 5. Архитектурные колонны [НОВОЕ]
В раздел «Архитектура» тулбара добавлен инструмент **«Колонна»** (иконка `mdi:pillar`):
*   Позволяет свободно размещать в пространстве вертикальные несущие железобетонные колонны прямоугольного сечения **400x400 мм** и высотой **3000 мм**.
*   Колонны рендерятся в виде реалистичных бетонных столбов с высококонтрастными графитовыми декоративными оголовниками и базами.
*   Интегрированы в систему SmartSnap для идеального позиционирования и полностью поддерживают выделение, перемещение и удаление.

### 6. Управление элементами с клавиатуры
*   **Удаление:** Клавиши **`Delete`** / **`Backspace`** мгновенно удаляют выбранный кастомный элемент, автоматически пересчитывая и регенерируя смежные соединительные фитинги.
*   **Перемещение стрелками:** Выбранный элемент можно сдвигать по сетке кнопками стрелок (Arrow keys):
    *   Шаг перемещения по осям X/Z составляет **100 мм** по умолчанию.
    *   Зажатая клавиша **`Shift`** переключает шаг в микро-режим **10 мм** для прецизионного выравнивания.
    *   После сдвига трасс автоматически запускается регенерация фасонных элементов.

### 7. Автоматическое восстановление хостов (Self-Healing Snaps)
Система отслеживает привязки дверей и окон к стенам, а также настенного оборудования (кондиционеры, розетки, радиаторы отопления, раковины, унитазы) в радиусе 400 мм. При черчении, сдвиге или модификации стен все хост-элементы автоматически «примагничиваются» обратно к плоскости стены, удерживая корректную ориентацию нормали.

### 8. Локальный оффлайн-запуск Web-IFC (Без CDN)
В отличие от стандартных решений That Open Engine, требующих загрузки бинарных файлов компилятора `web-ifc.wasm` из внешних CDN источников (unpkg.com), «Замоделька» настроена на **полностью изолированную работу**.
WASM-модули версии **0.0.72** упакованы в директорию `/public/web-ifc/` и загружаются локально с сервера. Внедрена система автоматического определения базового пути (`/zk/` на продакшене и `/` при локальной разработке) с отказоустойчивым оффлайн-резервированием, что исключает сбои САПР в закрытых корпоративных сетях.

## Технологический стек

### Фронтенд
*   **Core 3D САПР:** `@thatopen/components` (`~3.2.0`), `@thatopen/fragments`, `@thatopen/ui`
*   **Рендерер:** `three` (`0.175.0`)
*   **Сборка:** `vite` (`^7.1.5`), TypeScript
*   **Веб-интерфейс:** `@thatopen/ui` на базе Lit-представлений с адаптивной сеткой CAD.

### Бэкенд
*   **Фреймворк:** FastAPI (Python 3.10+)
*   **База данных:** SQLite (`vent_mvp.db` в корне проекта)
*   **Экспорт спецификаций:** Автоматическая генерация красивых спецификаций материалов и оборудования по ГОСТ в Excel (`xlsx`).
*   **Экспорт моделей:** Полный экспорт всей нарисованной сцены в трехмерный физический формат `IFC2x3`.

## Быстрый запуск

### 1. Локальная разработка

#### Запуск бэкенд-сервера:
```bash
# Перейдите в папку проекта
cd vent_mvp
# Активируйте виртуальное окружение Python
source server/.venv/bin/activate
# Запустите сервер FastAPI
python3 -m server.main
```
Сервер запустится по адресу: `http://127.0.0.1:8000`.

#### Запуск клиентской части:
```bash
# Установите зависимости (если требуется)
npm install
# Запустите Vite dev-сервер
npm run dev
```
Интерфейс САПР откроется по адресу: `http://localhost:5173/`.

### 2. Сборка и деплой на Production (VPS)
Статические файлы фронтенда собираются через Vite и раздаются веб-сервером Caddy:
```bash
# Сборка production билда
npm run build
# Синхронизация файлов на продакшн-сервер
rsync -avz --delete dist/ root@VPS_HOST:/var/www/zamodelka/
```
Проект развернут на удаленном VPS по адресу: **`https://les.ovc.me/zk/`**.
FastAPI сервер проксируется Caddy на порт `8000` в фоновом режиме.
