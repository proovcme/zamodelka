# MVP: Веб-моделлер вентиляции (Фаза 0)

Данный репозиторий содержит реализацию базового каркаса (Фазы 0) веб-моделлера вентиляции на базе That Open Engine с интеграцией с бэкенд-сервером на FastAPI и базой данных SQLite.

> 🤖 **ИИ-ассистентам и новым разработчикам:** перед любыми изменениями прочитайте
> **[`VENT_MVP_SKILL.md`](VENT_MVP_SKILL.md)** — подробное руководство по архитектуре,
> модели данных (мм↔метры), инструментам, генератору фасонных частей и неочевидным
> граблям BUI/lit, на которых легко сломаться.

## Локальный запуск проекта

Проект запускается локально без использования Docker.

### 1. Запуск бэкенда
Перейдите в папку проекта и выполните запуск сервера FastAPI:
```bash
# Активация виртуального окружения
source server/.venv/bin/activate

# Запуск сервера
python3 -m server.main
```
Сервер будет доступен по адресу: `http://127.0.0.1:8000`. При первом запуске база данных `vent_mvp.db` создастся автоматически и наполнится базовым сортаментом по ВСН 353-86.

### 2. Запуск фронтенда
В новом терминале в корневой папке проекта запустите Vite:
```bash
npm run dev
```
Клиентская часть будет доступна по адресу: `http://localhost:5173/`.

## Что сделано в Фазе 0

1. **Базовый каркас 3D-сцены:** Инициализирована чистая сцена That Open Engine с трехмерной сеткой, базовым светом, орбитальным управлением камеры и пост-обработкой.
2. **Веб-Воркер Fragments:** FragmentsManager инициализирован корректно через Vite-актив (`?url` импорт), что обеспечивает беспроблемную сборку воркера для production.
3. **Панели UI:** Добавлены разделы управления проектом («Сохранить», «Загрузить») и заглушка инструмента «Воздуховод» в секции «Вентиляция».
4. **Бэкенд интеграция:** Реализованы сохранения и загрузка графа проекта (`PUT/GET /projects/{id}`) с использованием локальной SQLite, а также получение детерминированного сортамента (`GET /sortament`). Идентификатор проекта автоматически сохраняется в `localStorage` браузера для поддержания сквозного сеанса.
