# Security

Если вы нашли уязвимость, не публикуйте детали в открытом issue.

Напишите владельцу репозитория через GitHub profile или создайте приватный канал связи. В сообщении опишите:

- затронутую часть проекта;
- шаги воспроизведения;
- возможное влияние;
- версию или commit, где проблема проявляется.

Проект ранний, поэтому SLA формально не задан, но критичные сообщения будут разбираться приоритетно.
