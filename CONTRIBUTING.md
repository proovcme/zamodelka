# Contributing

Спасибо за интерес к «Замодельке». Проект пока ранний, поэтому самые полезные вклады — короткие сценарии, баг-репорты с шагами воспроизведения и небольшие focused PR.

## Как работать локально

```bash
npm install
npm run dev
```

Перед PR проверьте:

```bash
./node_modules/.bin/tsc --noEmit
npm run build
```

## Инженерные правила

- Сохраняйте flow-first UX: пользователь выбирает сценарий, а не борется с панелями.
- Новые подключения добавляйте через `ConnectionNodes.connect` и конфиг `ConnectFlow`.
- Не копируйте state-machine для новых дисциплин.
- Геометрию и узлы проверяйте визуально в браузере.
- Документацию обновляйте вместе с поведением, особенно `README.md`, `TZ_FIELD_SKETCH.md` и `VENT_MVP_SKILL.md`.

## Pull Request

В PR укажите:

- что изменилось;
- как проверить вручную;
- какие команды запускались;
- есть ли ограничения v1.
